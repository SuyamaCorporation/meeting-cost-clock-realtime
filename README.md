# Real-time Meeting Cost Clock Calculator

Enter the number of attendees and average hourly salary to see a live cost ticker as the meeting runs. Start, pause, and reset the timer to track cumulative cost and elapsed time, with per-minute burn rate displayed. Agenda item mode lets you add topics with estimated minutes and tick them off one by one to see actual time and cost per item.

## Features

- Real-time cost ticker based on attendee count and hourly rate
- Start/pause/reset timer with elapsed time and cumulative cost display
- Per-minute and per-hour burn rate calculation
- Agenda item mode with estimated vs actual time and cost per topic
